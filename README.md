## 🧠 О проекте

**LinguaMaster** — это современное веб-приложение, созданное для эффективного изучения иностранных языков. Проект сочетает в себе **научно обоснованные методики** (интервальное повторение, активное вспоминание) с **игровыми элементами** и **социальным взаимодействием**.

### 🎯 Ключевые цели проекта:

- Помочь пользователям выучить **до 50 новых слов в день**
- Обеспечить **долгосрочное запоминание** через алгоритмы повторения
- Сделать процесс обучения **интересным и мотивирующим**
- Предоставить **персонализированный контент** под уровень пользователя
- Создать **сообщество** изучающих языки

### 🌟 Для кого это приложение:

| Категория | Описание |
|-----------|----------|
| 🎓 **Студенты** | Подготовка к экзаменам, расширение словарного запаса |
| 💼 **Профессионалы** | Деловой английский, переговоры, презентации |
| ✈️ **Путешественники** | Разговорные фразы, базовая лексика |
| 🎮 **Геймеры** | Игровой подход к изучению |
| 👨‍👩‍👧‍👦 **Семьи** | Совместное обучение для детей и родителей |

## ✨ Ключевые возможности

### 📚 Основной функционал:

- **🧠 Интервальное повторение** — алгоритм SM-2 для оптимального запоминания
- **🎙️ Озвучивание слов** — TTS (Text-to-Speech) с поддержкой 15+ языков
- **📝 Интерактивные упражнения** — 5 типов заданий (выбор, ввод, сопоставление, аудио, перевод)
- **📊 Детальная статистика** — прогресс по дням, неделям, месяцам
- **🏆 Система достижений** — бейджи, уровни, рейтинг
- **👥 Социальные функции** — друзья, турниры, общие курсы
- **🌙 Тёмная тема** — комфортное обучение в любое время
- **📱 Адаптивный дизайн** — работает на всех устройствах

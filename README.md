##  :relieved: *О проекте*
**Цель проекта** - создать интерактивное веб-приложение для эффективного изучения иностранных языков через интервальное повторение и игровые механики.

**Задачи** - разработать интерактивное приложение для изучения языков с карточками, упражнениями, статистикой и социальными функциями, помочь людям в изучении языков. 

**LinguaMaster** - современное веб-приложение для изучения иностранных языков через **интервальное повторение**, **интерактивные упражнения** и **социальное взаимодействие**.

**Для кого:**
1.  Студенты — подготовка к экзаменам
2.  Профессионалы — деловой язык
3.  Путешественники — разговорные фразы
4.  Геймеры — игровой подход

## :mortar_board: *Ключевые возможности*

-  Озвучивание слов 
-  5 типов упражнений
   - Выбор правильного перевода
   - Ввод с клавиатуры
   - Сопоставление
   - Аудио-викторина
   - Заполни пропуск
-  Статистика прогресса
-  Система достижений
-  Тёмная тема
-  Адаптивный дизайн


##  *Архитектура приложения*

Проект построен по трёхуровневой архитектуре:

**Клиентская часть:**
- Страница клиента (Элемент, проверка упражнений, кнопки "Знаю/Не знаю", уведомления)
- Если интернет пропал, данные сохраняются локально, а при восстановлении связи синхронизируются с сервером.

**Серверная часть:**
- Все запросы от клиента сначала попадают к нему, он их распределяет по нужным обработчикам.
- Сервисы: пользователи, карточки, статистика, рекомендации.
- Горячая линия для мгновенного общения.

**Хранилища:**
- _PostgreSQL_ — основная БД
- _Redis_ — кэш и очереди
- _S3_ — хранение файлов

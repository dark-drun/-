## 🧠 О проекте

**LinguaMaster** — современное веб-приложение для изучения иностранных языков через **интервальное повторение**, **интерактивные упражнения** и **социальное взаимодействие**.

**Для кого:**
- 🎓 Студенты — подготовка к экзаменам
- 💼 Профессионалы — деловой язык
- ✈️ Путешественники — разговорные фразы
- 🎮 Геймеры — игровой подход

---

## ✨ Ключевые возможности

- 🧠 Интервальное повторение (алгоритм SM-2)
- 🎙️ Озвучивание слов (TTS)
- 📝 5 типов упражнений
- 📊 Статистика прогресса
- 🏆 Система достижений
- 👥 Социальные функции (друзья, турниры)
- 🌙 Тёмная тема
- 📱 Адаптивный дизайн

---

## 🏗 Архитектура приложения

Проект построен по трёхуровневой архитектуре:

**Клиентская часть:**
- React SPA с Redux
- LocalStorage для офлайн-режима

**Серверная часть:**
- API Gateway на Express
- Сервисы: пользователи, карточки, статистика, рекомендации
- WebSocket для чатов

**Хранилища:**
- PostgreSQL — основная БД
- Redis — кэш и очереди
- S3 — хранение файлов

## ⚙️ Установка и запуск

### Требования

- Node.js 18+
- Docker + Docker Compose
- Git

### Быстрый старт (Docker)

```bash
# Клонирование
git clone https://gitlab.com/lingua-master/lingua-master.git
cd lingua-master

# Настройка .env
cp .env.example .env

# Запуск
docker-compose up -d --build

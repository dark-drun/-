## 🧠 О проекте

**LinguaFlow** — это современное веб-приложение для изучения иностранных языков через интервальное повторение, иммерсивное чтение и интерактивные упражнения.

Проект создан для тех, кто хочет:
- учить слова в контексте;
- отслеживать прогресс;
- тренировать произношение;
- погружаться в язык через тексты и аудио.

> 💡 **Фишка**: система адаптивного обучения на основе алгоритма SM-2 (Supermemo 2) с элементами ИИ-подсказок.

## ✨ Основные возможности

| Функция | Описание |
|---------|----------|
| 📚 Карточки слов | Интервальное повторение с подсчётом уровня запоминания |
| 🎧 Аудио-тренажёр | Озвучивание слов и фраз (TTS) |
| 📝 Тексты с подсветкой | Чтение с возможностью клика по незнакомым словам |
| 📊 Статистика | Прогресс по дням, неделям, темам |
| 🌓 Тёмная тема | Для комфортного обучения в любое время |
| 🔄 Синхронизация | Между устройствами через облако |
| 🧪 Мини-игры | «Сопоставление», «Заполни пропуск», «Аудио-викторина» |

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Frontend** | React + TypeScript + Vite |
| **State Management** | Redux Toolkit |
| **Backend** | Node.js + Express |
| **Database** | PostgreSQL + Redis (кэш) |
| **ORM** | Prisma |
| **Auth** | JWT + OAuth2 (Google, GitHub) |
| **TTS** | Google Cloud TTS / ElevenLabs |
| **Deploy** | Docker + GitLab CI/CD |
